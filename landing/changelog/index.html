Service Changelog

Public changelog for didaflow Studio, landing, and governance pages.

April 29, 2026

Studio and shared design system consolidation

Studio is the only implemented application surface. Landing, legal pages, assets, icons, and future UI work now inherit from the shared design system under shared/design.

  • Moved shared brand assets out of landing-specific folders.
  • Removed the landing build step in favor of static HTML served locally by the lightweight dev server.
  • Removed Tailwind from Studio and kept the visual layer in plain CSS.
April 29, 2026

Studio analytics services

Studio focuses on decision-support workflows for academic governance teams.

  • CSV, PDF, and document ingestion for institutional analysis.
  • Dropout-risk graph endpoints and cohort-level exploratory reports.
  • Conversation history and analyst-style report generation for governance workflows.
April 29, 2026

Governance and compliance pages

Legal and trust pages now use the same layout language as the home page.

  • Privacy Policy, Cookie Policy, and Terms of Service share one coherent footer and legal CSS layer.
  • Added a dedicated Data Processing Addendum separate from the Privacy Policy.
  • Updated navigation so Studio points to didaflow.ai/studio.
