# Changelog

Le novità del sito [didaflow.ai](https://didaflow.ai), versione per versione, scritte per chi lo visita.
Le note di prodotto su Maurice stanno nella pagina [Changelog](https://didaflow.ai/changelog/) del sito.
Le versioni sono i tag di questo repo; la più recente è in cima.

## 0.3.0

- **Il carattere dei titoli, Satoshi, è servito dal sito stesso.** Per mostrare le pagine il tuo browser non fa più richieste a Fontshare: nessun indirizzo IP arriva a terzi per questo.
- **Cookie policy, privacy policy e crediti aggiornati di conseguenza**, in italiano e inglese. Nei crediti Fontshare resta come origine di Satoshi, con la sua licenza.
- **Design system Didaflow alla versione 0.7.0.** L'aspetto resta lo stesso; i titoli possono risultare appena più larghi o più stretti (circa l'1%) perché Satoshi ora è un unico file variabile al posto dei quattro pesi separati.
- Per chi sviluppa: ritirata la CI di GitHub Actions; l'esito della suite di test si incolla nella pull request.
